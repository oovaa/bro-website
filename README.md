> **Bro CLI Landing Page** — Marketing website for the Bro CLI terminal AI assistant.

---

## 🎯 Overview

Landing page website for the **Bro CLI** — a terminal-based AI assistant powered by DeepSeek. Built with modern web technologies for a fast, responsive experience.

---

## 🛠 Tech Stack

| Category | Technologies |
|----------|--------------|
| **Framework** | React 18+ / Next.js |
| **Language** | TypeScript |
| **Styling** | Tailwind CSS |
| **Deployment** | Vercel / Netlify |

---

## 🚀 Quick Start

```bash
git clone https://github.com/oovaa/bro-website.git
cd bro-website

npm install
npm run dev
```
